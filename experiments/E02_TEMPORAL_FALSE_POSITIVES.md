# E02 Temporal Hard-Negative Analysis

## Purpose

Measure whether temporal coordination features change false-positive
rates on legitimate customers that share infrastructure.

## Previous static-graph result

- Shared-IP false-positive rate: 0.1497
- Shared-device false-positive rate: 0.0636

| ---------------------------- | ------------ | ------- | ------------------- |
| Shared-IP benign traffic     | 788          | 147     | 0.1865              |
